Lichess-MakeChessBetter Documentation
=====================================

Welcome to the documentation for Lichess-MakeChessBetter! This is a fully adaptive Lichess chess bot that dynamically matches its strength to your live skill level using real-time centipawn loss analysis.

.. toctree::
   :maxdepth: 2
   :caption: Contents:

Quick Start
-----------

To run the project directly from the source code, install the requirements and run the bot module:

.. code-block:: bash

   pip install -r requirements.txt
   python -m src.bot
