# AI Context Configuration Folder

This folder contains the project profile configurations and system prompt rules for artificial intelligence programming assistants (such as Qwen, Claude, or ChatGPT).

## 📁 Folder Contents
* **`ai.md`**: The master system prompt detailing project context, tech stack rules, and critical engine calculation warnings.
* **`settings.json`**: Standard settings properties for local IDE editor extensions.

*Note: This configuration is brand-neutral to support diverse open-source contributors and keep the repository root clean.*
